01THE IDEA
From molecules to a cellular panorama

Give every gene
a place in the picture.

Gene sequences provide identity. Expression provides the signal. A structured image brings them into the same cellular context, across coding and non-coding genes.

A T G C A C T G
T A C G T G A C
DNA → GENE IDENTITY
01

Start with identity

DNA-derived representations describe genes, including those without a protein product, and define a species-specific spatial layout.

384 × 384 PIXELS
02

Make expression visible

Measured RNA expression fills a 384 × 384 canvas. A separate measurement mask preserves the difference between an observed zero and an unmeasured gene.

→
768-D CELL REPRESENTATION
03

Learn the cellular context

Multiview latent learning builds cell representations. A gene-conditioned decoder connects that context back to individual gene expression.
