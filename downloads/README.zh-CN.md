# CellNet Image atlas

`CellNet_pretraining_example_24cells.zip` 为可直接读取的真实预训练示例：小鼠、斑马鱼、果蝇各 8 个细胞，共 24 个，包含原始存储表达数组、数据集特异的实测基因掩码、原生基因 ID、共享基因词表、拟合布局、格式说明和图片。公开样本 ID 已匿名化；保留物种、细胞类型和来源数据集信息。

## Image atlas：敬请期待

完整 CellNet Image atlas（预训练图像集合）敬请期待。源元数据记录的完整图谱规模为 231,190,557 个细胞、26,467 个数据集、40 个物种和 1,015,163 个词表条目。当前示例包提供上述 24 个真实细胞，便于探索数据格式与读取流程。完整集合开放时将提供文件清单与校验值，当前可用状态见 `FULL_DATA_STATUS.json` 中的 `coming_soon`。

表达已归一化到 [0,1]，请勿重复归一化。实测但为零的像素仍为 mask=1；未测量像素为 mask=0、gene ID=0。图片由真实转录组表达计算渲染，便于查看表达纹理。示例可用于格式检查和数据读取演示。

SHA256SUMS 提供校验值，FILE_CATALOG.json 提供文件目录，DATASET_CARD.json 说明范围和状态。原数据许可与署名要求继续适用；软件的 Apache-2.0 不自动覆盖第三方数据，逐来源数据许可核验仍待完成。
